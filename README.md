# Alwebify

Website jasa pembuatan website Alwebify: landing page, company profile, toko online, dan web custom.

## Halaman

- `index.html` – Beranda
- `layanan.html` – Layanan
- `tema.html` – Referensi tema desain
- `harga.html` – Paket harga
- `faq.html` – Pertanyaan umum
- `kontak.html` – Kontak dan formulir konsultasi

Tampilan bersama ada di `styles.css`, fungsi bersama di `app.js`, foto tema di `img/`, dan file logo di `logo/`.

Foto tema dari [Unsplash](https://unsplash.com) (Unsplash License).
